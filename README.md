# 🛡️ End-to-End MLOps Fraud Detection System

An enterprise-grade MLOps pipeline and web application designed to detect fraudulent mobile money transactions in real-time. Built using modular architecture principles, automated logging and exception handling, dynamic timestamped artifact management, and an interactive user interface.

---

## 📊 Dataset

This project utilizes the **Synthetic Financial Datasets For Fraud Detection** generated by the **PaySim** mobile money simulator. 
* **Dataset Source:** [Kaggle - PaySim Synthetic Financial Datasets](https://www.kaggle.com/datasets/ealaxi/paysim1?resource=download)
* **Description:** PaySim uses aggregated data from a private mobile money dataset to generate synthetic logs that mimic normal user behavior while injecting fraudulent activities (such as unauthorized transfers followed by cash-outs).
